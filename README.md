## What the extension does

It checks the page you are on against the rules search engines publish for rich results:
JSON-LD, microdata and RDFa coverage, 20+ schema types, schema.org vocabulary and value
checks (dates, currencies, prices, ratings, URLs, enums). Free to install; the Pro licence
adds a site audit (up to 200 URLs), a client-ready report and a JSON-LD builder.
Everything runs in the browser: no account, no upload, no tracking.
