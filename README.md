# SchemaProof — public site

The static pages for **SchemaProof**, a structured-data inspector browser extension
for Microsoft Edge and Mozilla Firefox.

| Path | Purpose |
|---|---|
| `index.html` | Product landing page |
| `privacy-policy.html` | Privacy policy (the URL used on the Edge Add-ons and Mozilla AMO listings) |
| `icon-128.png` | Icon used on both pages |
