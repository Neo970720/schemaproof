See exactly why a page is not getting rich results.

SchemaProof checks the page you are on against Google’s published structured-data rules and shows every problem with its property path, what is wrong and how to fix it. Everything runs in your browser — no account, no upload, no tracking.

Get the extension Pro — $19 once

Free edition for Microsoft Edge and Mozilla Firefox. Pro is a one-time licence, no subscription.

What a scan gives you

  • Every JSON-LD block, microdata item and RDFa item on the page
  • Rich-result checks for 20+ schema types
  • schema.org vocabulary: unknown types, properties, misspellings
  • Value checks: dates, currencies, prices, ratings, URLs
  • Findings as text or CSV, with the exact property path

Three things it does

The markup is what search engines read. One missing price or one broken quote makes the rich result disappear silently.

01 — SCAN

One-page scan

Press the toolbar button. The page is read locally, parsed for JSON-LD, microdata and RDFa, and checked against Google’s rich-result requirements and the current schema.org vocabulary.

02 — AUDIT

Site audit

Paste up to 200 URLs or point it at sitemap.xml. Each page is fetched once, without cookies, directly from your browser and checked with the same rules.

03 — BUILD

JSON-LD builder

12 guided templates — Product, Article, LocalBusiness, Event, Recipe, FAQ, Breadcrumb, Video, Job, Course, Software, Organization — validated live while you type.

Install

SchemaProof is published in the Microsoft Edge Add-ons store and on Mozilla Add-ons (AMO). Both listings are free.

Microsoft Edge Add-ons Mozilla Add-ons (Firefox)

Store links appear here once each listing is approved. The licence key is checked with Gumroad only when you press “Verify key” — that is the only network request the extension makes.

Privacy, in short

The full policy is at privacy-policy.html.

Page content never leaves your device. The page is read only after you click the toolbar button, and the HTML is parsed in the extension itself.

No analytics and no profile. No telemetry, no crash reporting, no advertising identifiers, no browsing history.

The one network call. If you enter a Pro licence key, the key and the product id go to Gumroad’s licence API to check it. Nothing about the page or the browser is included.
